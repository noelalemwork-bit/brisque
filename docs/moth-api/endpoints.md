engines​

EndpointWhat it doesGET/enginesList engines. Lists visible engines by ID ascending.POST/enginesCreate engine. Creates a personal engine owned by the caller, or an organization engine when organization_id is provided and creation policy permits it.GET/engines/{engineID}Get engine. Returns the full definition of a visible engine, including its params schema.PATCH/engines/{engineID}Update engine. Partially updates an engine; omitted fields keep their current value.POST/engines/{engineID}/transferTransfer a personal engine to an organization.  Requires a Supabase access JWT and a current active account.
jobs​

EndpointWhat it doesPOST/engines/{engineID}/processSubmit a job. Validates params against the engine's schema, records the job, and starts the workflow.GET/jobsList jobs. Lists the caller's jobs newest first with the status last persisted to job history; poll get-job-status for live workflow state.GET/jobs/{jobID}Get a job. Returns the recorded job row without querying the execution backend; poll get-job-status for live workflow state.GET/jobs/{jobID}/resultGet a job's result. Returns the completed job's outputs: one entry per declared output_files slot, each with a presigned download URL (every output is also recorded as a kind=output asset), or the inline JSON result for engines that produce no files.GET/jobs/{jobID}/statusGet job status. Returns the live status of a job with view access.
